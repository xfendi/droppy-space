# Contributing to Droppy

Droppy is a static gallery of app icons and website logos for inspiration.

For security issues, email [xfendi.studio@gmail.com](mailto:xfendi.studio@gmail.com) privately with reproduction steps. Use public issues for ordinary bugs and app requests.

## Request an app

Open a [GitHub issue](https://github.com/xfendi/droppy-space/issues) with the app name, its website or store link, and its current official icon image or a link to it. Check existing issues and the gallery for duplicates first.

Real, released mobile apps and live websites are welcome. Use current official icons, not concepts, placeholders, fan redesigns, or archived versions.

## Update the catalog

You can also add or edit entries in `data/apps.ts` and submit a pull request. Keep slugs unique and preserve existing icon URLs. For a new app, include its current official icon image with the pull request, or send it to the maintainer through the [contact page](https://droppy.space/contact). The maintainer uploads the image and sets the final icon URL before merging.

Run `npm run lint` and `npm run build` before sending a pull request. Include a screenshot for visual changes.

## Report a problem

For bugs, include what happened, what you expected, your browser and device, and a screenshot if useful. For an incorrect or outdated icon, include the app name and a link to its current official icon.

For rights or removal requests, use the [contact page](https://droppy.space/contact). Icons and trademarks belong to their respective owners.

For larger code changes, open an issue first to agree on the approach. Keep contributions focused and respectful.
